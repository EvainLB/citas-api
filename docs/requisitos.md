# Requisitos del MVP

## Funciones que SÍ entran (MVP)
- [ ] El administrador gestiona servicios y empleados
- [ ] El cliente se registra y agenda citas
- [ ] No se pueden empalmar citas del mismo empleado
- [ ] ni horarios si ambos trabajadores estan ocupados debe decir no disponible
- [ ] bloqueos de horario, avisos por Telegram a la dueña, vista de calendario con horarios disponibles, y que la dueña edite su disponibilidad.

## Futuro (no entra ahora)

- Reseñas
- noticias en la patalla principal de cursos y ofertas
- si se pide adelanto poder anexar una captura del deposito o transferencia bancaria
